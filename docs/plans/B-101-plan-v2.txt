1. Goal

Add a script that renders all 79 figures and 19 legends from FAA-CT-8080-2H
(references/sport_rec_private_akts.pdf). Each item becomes one image: the
figure or legend body plus its printed caption and any note printed under the
caption, with no "Appendix N" header and no page number. When the body is
printed sideways, only the body is turned upright. The upright caption block
is then placed centred beneath it. Each item is written to figures/ as a
lossless PNG and a WebP for the site. figures/index.json records both files,
the body and caption crops, the turn, the source PDF's SHA-256 and the tool
versions. The builder writes the code. Architect-Claude runs it in the Linux
workspace and checks every image by eye. Nothing in figures/ is committed
until that check passes. Backlog item: B-101.

4.4 scripts/qbank/lib/data.ts

checkFigureIndex(raw, docs: ReferenceDoc[] | null) follows the same pattern
as checkAcs. It collects every error and rejects the following.

Index level:

- source_doc or items is missing.
- Any top-level key other than source_doc, source_sha256, extracted_with,
  items.
- source_sha256 is not 64 lowercase hex.
- extracted_with is not null while items is empty, or is null while items is
  not empty.
- When extracted_with is an object:
  - It must have exactly the keys in FigureExtraction, including the png and
    webp sub-objects.
  - poppler, sharp and libvips are non-empty strings.
  - dpi is a positive integer.
  - ink_threshold, margin_px and pad_px are non-negative integers.
  - The png and webp fields have the types shown in 4.3.

Item level:

- Unknown keys. This catches a stale v1 index that has crop_px or file.
- All existing checks on key, type and number. Keep FIGURE_KEY_RE.
- page is not a positive integer.
- printed_page does not match ^[12]-\d+$, or its appendix digit doesn't fit
  the type (1 for a legend, 2 for a figure).
- rotate is not 0, 90, 180 or 270.
- body_px or caption_px is not 4 non-negative integers with a width and
  height of at least 1.
- rotate is not 0, but body_px top + height is greater than caption_px top.
  Error text: "${where}: body_px must end above caption_px when rotate is
  not 0".
- files does not have exactly the keys png and webp.
- A file name is not exactly ${key}.png or ${key}.webp.
- width, height or bytes is not a positive integer.
- sha256 is not 64 lowercase hex.
- webp.lossless is not a boolean.
- The PNG and WebP width or height differ.
- Duplicate keys (existing check).

Cross-check: if docs is not null and has an entry for source_doc,
source_sha256 must equal its sha256. Error text: "figures/index.json
source_sha256 does not match the akts-2h sha256 in references.json".

4.7 New: scripts/qbank/lib/figures.ts (pure: no I/O, no Poppler, no sharp)

Constants. Write all of these as literals. Don't compute or range-generate
the expected sets.

- RENDER_DPI = 300. S = 300/72 (points to pixels).
- EXPECTED_PAGE_COUNT = 113.
- PAGE_PT = {w: 594, h: 774}. PAGE_PX = {w: 2475, h: 3225}.
- INK_THRESHOLD = 250. A pixel is ink if any channel is below 250.
- MARGIN_PX = 24. This is the white margin around the image, and also the
  gap between a turned body and its caption.
- PAD_PX = 4. Each crop is padded by this much, to keep anti-aliased edges.
- TOP_STRIP_END_PT = 48.0. The top strip is y < 48.0 pt; in pixels, rows
  0 to 199.
- BOTTOM_STRIP_START_PT = 725.0. The bottom strip is y >= 725.0 pt; in
  pixels, rows 3021 to 3224 (ceil(725 x S) = 3021).
- HEADER_WINDOW_PT:
  - yMin >= 32.0 and yMax <= 46.5.
  - x either within [30, 78] (left) or within [508, 557] (right).
- PAGENUM_WINDOW_PT: yMin >= 726.0, yMax <= 742.0, and the centre x within
  297 +/- 10.
- STRIP_WORD_PAD_PT = 3. Ink within this distance of a header or page-number
  word box is that word's ink.
- CAPTION_TOL_PT = 1.0.
- MIN_WORD_CHARS = 3. MIN_DETECT_WORDS = 8. SIDEWAYS_SHARE = 0.65.
- DIRECTION_MIN_VOTES = 3. DIRECTION_AGREEMENT = 0.9.
- PPI_WARN = 330. WEBP_PSNR_WARN_DB = 35.
- WEBP = {quality: 90, effort: 6, smartSubsample: true,
  losslessForGrayscale: true}.
- PNG = {compressionLevel: 9, adaptiveFiltering: true, palette: false}.
- EXPECTED_FIGURES and EXPECTED_LEGENDS: explicit arrays of numbers (1-15,
  17-28, 31-82 written out; 1-19 written out).
- KNOWN_NOT_IN_CONTENTS = ['fig-55'].

Text and mapping:

- parseBboxLayout(xhtml): reads Poppler pdftotext -bbox-layout output into
  pages, then lines (keeping Poppler's line grouping and word order), then
  words with xMin, yMin, xMax, yMax in points. It decodes the five XML
  entities and numeric entities.
- classifyPages(pages): a caption line is one whose text matches
  ^(Figure|Legend)\s+(\d+)\.(\s|$).
  - 0 caption lines: not an item page.
  - 1: an item page.
  - 2: an error.
  - 3 or more: a contents page. Its entries are kept for the cross-check.
- Mapping checks. Collect every problem before failing:
  - Duplicate key (name both pages).
  - Key not in the expected set.
  - Expected key not found.
  - Contents entries vs. found items: any difference other than
    KNOWN_NOT_IN_CONTENTS is an error. fig-55 is reported as a note.

Strips (fixed; replaces v1's header bands). For each item page,
checkStrips(page) collects errors:

- Exactly one header group: the word "Appendix" plus the next word on the
  same line, which must be the appendix digit (1 for legends, 2 for figures).
  Both word boxes must be inside HEADER_WINDOW_PT, on the left side or the
  right side. Record the side.
- Exactly one page-number word matching ^[12]-\d{1,2}$, with the same
  appendix digit. Its box must be inside PAGENUM_WINDOW_PT.
- Any other word whose box touches a strip is an error, naming the word and
  the page.
- Within an appendix, printed page numbers rise by exactly 1 from one item
  page to the next.
- Every error names the page, the word and its box, so a position that
  differs from the confirmed one fails loudly.

Partition into body and caption block (text), partitionWords(page):

- Caption line top = the smallest yMin among the caption line's words.
- Caption-block words: words outside both strips whose yMin >= caption line
  top - CAPTION_TOL_PT. That is the caption line plus every line printed
  beneath it.
- Body words: every other word outside both strips.
- Error: no body words and (later, from pixels) no body ink. Message:
  "nothing printed above the caption on page P".

Orientation detection, detectOrientation(bodyWords):

- Count body words with at least MIN_WORD_CHARS characters (trimmed text, in
  Unicode code points). A word is sideways if (yMax - yMin) > (xMax - xMin).
- n = the counted words; share = sideways / n.
- Result:
  - n < MIN_DETECT_WORDS: "undetermined" (raster or sparse body).
  - share >= SIDEWAYS_SHARE: "sideways".
  - Otherwise: "upright".
- Report n, the sideways count and the share for every page.
- Why these values: the sideways items score 78-100% and the highest upright
  score is 50% (fig-48, 10 words), so 0.65 leaves a margin on both sides.
  The minimum keeps a raster page with a few printed labels from counting as
  a text page.

Direction, for "sideways" results only, detectDirection(lines):

- Within each Poppler line, take consecutive pairs of words that both have
  at least MIN_WORD_CHARS characters and are both sideways. Each pair is one
  vote: dy = centreY(second) - centreY(first). dy < 0 means bottom-to-top;
  dy > 0 means top-to-bottom; dy = 0 is ignored.
- Fewer than DIRECTION_MIN_VOTES votes, or the winning direction under
  DIRECTION_AGREEMENT of the votes: error "reading direction undetermined
  for KEY (votes up U, down D)".
- Bottom-to-top text needs rotate 90 (clockwise). Top-to-bottom text needs
  rotate 270.
- This relies on Poppler listing a rotated line's words in reading order.
  The literal legend-1 = 90 in the real-data test and the eye checks both
  catch it if that's wrong.

Rotations file:

- checkRotationsFile(raw, docs) rejects:
  - Keys other than source_doc, source_sha256, rotations.
  - source_doc that isn't "akts-2h".
  - source_sha256 that differs from akts-2h in docs.
  - An entry whose keys aren't exactly key, rotate, evidence.
  - A key that is malformed, not in the expected set, or listed twice.
  - rotate not 90, 180 or 270 (0 is never listed).
  - evidence not "words" or "visual".
  - evidence "words" with rotate 180 (detection can't see upside down).
- compareRotations(file, detections) returns errors and notes:
  - Detected "sideways" with no entry: error, "KEY is printed sideways (N of
    M body words); add { "key": "KEY", "rotate": R, "evidence": "words" }".
  - Detected "sideways" with evidence "visual": error, "KEY was found from
    its words; set evidence to words".
  - Detected "sideways" with evidence "words" but a different rotate: error,
    naming both angles.
  - Detected "upright" with any entry: error, "the rotations file turns KEY,
    but its body text is upright (share S of N words)".
  - "undetermined" with evidence "words": error, "KEY has too few body words
    to detect; use evidence visual".
  - "undetermined" with evidence "visual": accepted, and listed in the
    report as "rotation confirmed by eye only".
  - "undetermined" with no entry: rotate 0, listed in the report as
    "undetermined; upright by default; check by eye".

Pixels, crops and composition. All functions take raw 8-bit RGB buffers
(3 channels, row-major):

- checkStripInk(rgb, stripWordBoxes): ink in either strip outside the header
  and page-number word boxes (each padded by STRIP_WORD_PAD_PT and converted
  with floor for minimums and ceil for maximums) is an error. Report the
  count and the bounding box. Printed content must never be dropped
  silently.
- computeCrops(rgb, words, partition, rotated) returns body_px, caption_px
  and diagnostics.
  - capTopPx = floor(caption line top x S) - PAD_PX.
  - Caption zones: each caption-block word box in pixels, padded by PAD_PX.
  - Each ink pixel outside the strips is classified as follows:
    - Above capTopPx: body ink.
    - At or below capTopPx and inside a caption zone: caption ink.
    - At or below capTopPx and outside every caption zone: when rotated,
      error "ink beside the caption block on page P" (count and box); when
      upright, body ink.
  - Body tight box = bounding box of the body ink and the body word boxes.
    Caption tight box = bounding box of the caption ink and the caption-block
    word boxes.
  - When rotated: error if the body tight box's bottom edge (exclusive) is
    below capTopPx: "body reaches the caption block on page P".
  - When rotated: error if any caption-block word with at least
    MIN_WORD_CHARS characters is sideways: "caption block on page P contains
    sideways text".
  - Error if the body tight box is empty.
  - body_px = the body tight box padded by PAD_PX, clamped to columns
    0-2474. Its rows are clamped to start below the top strip, and to end at
    capTopPx when rotated or at the bottom strip when upright.
  - caption_px = the caption tight box padded by PAD_PX, clamped to columns
    0-2474 and to rows from capTopPx to the bottom strip.
  - Source region R: for upright items, U = the smallest rectangle
    containing body_px and caption_px; for rotated items, the two rectangles
    themselves.
  - Diagnostics:
    - inkOutside: ink outside the strips and outside R. Must be 0. Any other
      value is an error and a bug.
    - faintOutside: pixels with any channel below 255 outside the strips and
      outside R. A warning, with the count and the box.
    - touchesEdge: a crop that reaches column 0 or 2474, or a strip
      boundary. A warning, naming the side.
  - Every word outside the strips must lie inside body_px or caption_px. If
    not, it's an error and a bug.
- cropRgb(rgb, w, h, rect) returns the rectangle.
- rotateRgb(rgb, w, h, angle), exact pixel mapping with no resampling. For
  output pixel (x, y):
  - 90: output is h wide and w high; out(x, y) = in(y, h - 1 - x).
  - 180: output is w by h; out(x, y) = in(w - 1 - x, h - 1 - y).
  - 270: output is h wide and w high; out(x, y) = in(w - 1 - y, x).
- composeItem(rgb, item fields) builds the final image on a white (255)
  canvas:
  - rotate 0: the canvas is U.w + 2M wide and U.h + 2M high. Paste the
    render's U at (M, M). This keeps the printed layout exactly.
  - rotate 90, 180 or 270: B = rotateRgb(cropRgb(body_px), rotate) and
    C = cropRgb(caption_px). The canvas is max(B.w, C.w) + 2M wide and
    B.h + C.h + 3M high. Paste B at (floor((W - B.w) / 2), M) and C at
    (floor((W - C.w) / 2), 2M + B.h).
  - M = MARGIN_PX.
- isGrayscale(rgb): true only if every pixel has R = G = B.
- psnr(a, b).
- versionGuardDecision(existingIndex, currentVersions, allowFlag).
- formatSizeReport(items).

4.10 New: scripts/qbank/extract-figures.ts

Flags:

- --out DIR: default is the repo's figures/.
- --only KEY,...: refused unless --out points somewhere other than the repo's
  figures/.
- --allow-version-change.

Usage errors are checked before any tool lookup, and exit with code 2. The
script reads references/ only and never writes there.

Steps:

1. Preflight:
   - The PDF's SHA-256 must equal akts-2h.
   - data/figure-rotations.json must pass checkRotationsFile.
   - Poppler lookup (4.8).
   - pdfinfo -f 1 -l 113 -box: 113 pages, each 594 x 774 pt, rot 0,
     MediaBox = CropBox. Anything else is an error.
   - pdffonts on each item page: a font that isn't embedded is a warning.
   - pdfimages -list: an image above PPI_WARN is a warning.
2. Text: one call, pdftotext -bbox-layout -enc UTF-8 -f 1 -l 113, into a
   temp folder. Then parseBboxLayout.
3. Mapping: all the mapping checks in 4.7.
4. Strips: checkStrips on every item page.
5. Partition and detection: partitionWords, detectOrientation and, for
   sideways pages, detectDirection. Run the text-only partition checks for
   every item that is detected sideways or listed in the rotations file:
   - A sideways caption-block word.
   - A body word reaching the caption rows.
   - No body words. On text pages this is an error here; on undetermined
     pages, wait for the pixel check.
6. Rotations: compareRotations.
   --survey prints one block per item page and stops here:
   - Page, printed page, key and caption text.
   - The caption block's extra lines.
   - Header side.
   - n, sideways count, share, result, direction and votes.
   - The rotations-file entry.
   - Highest image ppi and fonts not embedded.
   Then it prints a "suggested entries" JSON block with one
   {"key", "rotate", "evidence": "words"} per detected sideways item, in
   index order, and lists the undetermined items for an eye check.
   Exit codes:
   - 1 if steps 1-5 found any error.
   - 0 otherwise.
   - Differences between the rotations file and detection are printed as
     "to do", not errors, because the file is being prepared.
   Without --survey, any compareRotations error stops the run with exit 1.
7. Version guard: if --out already holds an index with items, and its
   Poppler, sharp or libvips version differs from the current tools, refuse
   without --allow-version-change. The message warns that every file would
   get new bytes, adding roughly 200 MB of new git history.
8. Per item. Collect errors across all items, and keep going:
   - Render: pdftoppm -r 300 -f P -l P -singlefile -png -aa yes -aaVector
     yes into the temp folder.
   - Decode with sharp to raw 3-channel RGB. Require 2475 x 3225 and 3
     channels.
   - rotate = the rotations-file entry, or 0.
   - Run checkStripInk, then computeCrops (rotated = rotate is not 0), then
     composeItem. Assert the composed size equals the formula in 4.7.
   - isGrayscale decides gray or RGB.
   - PNG: write with sharp from the composed raw buffer, using PNG settings.
     Gray images are one-channel 8-bit gray. No metadata or ICC profile, and
     the output is treated as sRGB. Decode the written PNG and require it to
     match the composed pixels exactly, so the copy is proven lossless.
   - WebP:
     - Gray images: webp({lossless: true, effort: 6}).
     - Colour images: webp({quality: 90, effort: 6, smartSubsample: true}).
     - Decode the WebP, compute PSNR against the composed pixels, and warn
       below 35 dB (lossy only).
   - All outputs go to the temp folder first.
9. Finish:
   - Only if every item succeeded, copy the files into --out, then write
     index.json last.
   - Items are ordered figures by number, then legends by number.
   - The JSON uses 2-space indents, a trailing LF and no timestamps, so two
     runs with the same tools and rotations file give identical output.
   - extracted_with.libvips comes from sharp.versions.vips.
   - Run verifyFigureFiles on --out and print its report.
   - Always delete the temp folder, in a finally block.
10. Report:
    - One line per item, for example:
      legend-1  p13  1-1  rot 90 (words)  body 2050x2700  caption 560x60
      out 2748x2182  gray  png 3,456,789  webp 1,234,567 (lossless)
    - Then every warning, grouped by item.
    - Then the "confirmed by eye only" and "undetermined" lists.
    - Then the tool versions.
    - Then the size report:
      - Items: 98 (79 figures, 19 legends), the number rotated (words /
        visual) and the number grayscale.
      - PNG: N files, B bytes (MiB). WebP: N files, B bytes (MiB).
      - The five largest files of each format.
    - Exit 1 on any error. Warnings don't change the exit code.

7. Risks
8. Git history size. The PNGs are about 200 MB, and history keeps every
   version. Re-running with the same tools gives identical bytes (checked in
   section 9). Different tool versions rewrite every file. Mitigations:
   - The eye check and the 300 MB gate both come before commit 2.
   - The version guard.
   - figures:check, so nobody re-renders just to verify.
9. Poppler version differences: anti-aliasing, JPEG 2000 decoding, fonts
   that aren't embedded, and small bbox shifts.
   - The strip windows and the detection share depend on bbox output.
   - Versions are recorded and the check mode doesn't use Poppler.
   - A different Poppler that moves a header outside its window fails
     loudly; it doesn't crop wrongly.
10. Xpdf passing as pdftotext on Windows. Handled by the refusal in 4.8.
11. Fixed strips. Any printed content inside a strip is an error, not a
    warning (checkStripInk, and words in strips).
    - If that ever fires on a decoration that appears on every page, stop and
      come back to the planner. The builder and architect must not widen the
      windows or turn the error into a warning.
12. Very light tints (above 250 in every channel) outside the ink box are not
    copied, because margins are white canvas. Caught by the faintOutside
    warning and the eye check.
13. Rotation.
    - Detection uses Poppler's word boxes and word order.
      - Wrong word order would flip 90 and 270. That is caught by the
        literal legend-1 = 90 in the real-data test and by the eye check.
    - Raster bodies and upside-down pages are found only by eye. Every
      undetermined item and every "visual" entry is listed in the report.
    - The caption-block rule assumes the caption sits below the body with
      nothing beside it on sideways pages. If not, the run fails loudly (ink
      beside the caption, body reaching the caption, a sideways word in the
      caption block, or nothing above the caption).
    - A sideways word of 1-2 characters beside the caption isn't caught by
      the sideways-word check. It is left to the eye check.
14. Runtime: rendering 98 pages at 300 dpi with JPEG 2000 may take several
    minutes. Run it in the background, or batch with --only into a scratch
    folder. The 176 MB PDF must be in the workspace.
